# Deutsche Börse

> Deutsche Börse AG is the Frankfurt-based exchange group behind the Frankfurt Stock Exchange, Xetra, Eurex, EEX, 360T, Clearstream and ISS STOXX. Its Market Data + Services arm exposes a self-serve Group API Platform (X-DBP-APIKEY auth), the A7 Analytics Platform cloud REST API (Bearer auth) for nanosecond order-by-order Eurex/Xetra/EEX/CME history, a free Eurex T7 reference data GraphQL API, and the Cloud Stream real-time WebSocket feed (protobuf/JSON).

Generated by API Evangelist from the harvested artifacts in this repository (no provider llms.txt exists; probed 2026-07-22).

## APIs

- [A7 Analytics Platform](https://a7.deutsche-boerse.com/): REST base https://a7.deutsche-boerse.com/api/v1, Bearer token from the A7 GUI. Order books, EOBI/MDP raw market data, RDI/SD reference data, algos, precalc, datasets, insights, option analytics, auction simulations.
- [Eurex T7 Reference Data API](https://www.eurex.com/ex-en/data/free-reference-data-api): free GraphQL API at https://api.developer.deutsche-boerse.com/eurex-prod-graphql/ with a published shared rate-limited X-DBP-APIKEY; products, contracts, trading hours, settlement prices.
- [Cloud Stream Market Data](https://github.com/Deutsche-Boerse/Cloud.Stream.Client): real-time WebSocket feed at wss://md.deutsche-boerse.com, protobuf or JSON messages, API key from the GUI.
